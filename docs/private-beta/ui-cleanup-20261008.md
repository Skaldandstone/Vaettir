- TestRail: the existing synthetic run exposes tree grouping, status distribution, remaining tests, and separate Progress/Activity views. Progress distinguishes actual completion/elapsed time from estimates and forecasts. No execution results or run settings were changed.

These observations establish comparison inputs, not parity or superiority. Raw page histories, credentials and screenshots stay local. Do not copy vendor branding, assets or source.

## Repository connection target

The ordinary flow is Access → Scope and repositories → Review. Show permission breadth and the exact account/group, discover authorized groups/projects, preserve native identities, and support reviewed multi-repository selections. Never label a partial or truncated catalogue as all repositories. Preserve durable uncertain saves and current actor/tenant/CAS safeguards.

GitHub App installation is distinct from the present broad OAuth connection. Self-hosted GitLab needs an application on that instance before consent. Azure and Bitbucket native sign-in also need their real registered integrations; token forms must not be relabeled as OAuth. Keep one-time operator setup out of ordinary users' checklist flow. Metadata connection is not authorization or capability proof for private source processing.

## Expanded live-testing requirements

An approved testing agent should execute scoped actions, collect assertions/evidence, match existing case identities, and propose enrichment or new cases through review without replacing manual work. Targets include desktop applications/games, USB/Wi-Fi ADB devices including cameras/embedded devices, medical simulators/test hardware, licensed console development hardware, and authorized aviation HIL rigs such as iron birds.

Target options appear only when enabled for the project and when the adapter truthfully reports its capabilities. Capture, control, telemetry and assertions are separate. Unsupported adapters remain unavailable, not simulated as working hardware. Network pairing, safety-critical commands, spending, sensitive submissions and external source/AI processing require their applicable explicit approvals. Rig interlocks/operator authority and medical test isolation are not feature flags that can be bypassed.
