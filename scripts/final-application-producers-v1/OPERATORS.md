# Final application producers v1

This is a Main-coordinated **source-only** successor to frozen `8a0cb375` and
`8b7d9f0f`. It supplies missing producers. It does not execute builds, Docker,
PostgreSQL, native probes, provider calls, devices or browsers. Only Main may
perform those operations after independently reviewing exact source and inputs.
Do not modify frozen packages. No generated output declares release, hosted,
production, native or extended-metadata acceptance.

## Entry point and review

Merge the extension template into the final release bindings; retain every
frozen binding. Nulls are intentional missing actual evidence, not defaults.
All refs are `{path,sha256,bytes}` relative to the evidence root. The source
admission still requires exact final Git/tree, successful main CI, privacy,

The manifest has `files` equal to `packageRows(packageDirectory)`. No approval
